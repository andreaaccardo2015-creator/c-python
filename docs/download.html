Download

Versione 0.3.5. I file pronti stanno solo nel repository cpython-setup, cartella installer/. Il codice sorgente è un altro repo.

Windows

Cpython_interpreter_64x_win.exe
64 bit · circa 23 MB
  1. Scarica l’exe.
  2. Doppio click: installa demone, comando cpy e associazione dei file.
  3. Apri un nuovo terminale e prova cpy version.
Scarica per Windows

macOS

Cpython_interpreter_macos.dmg
Intel e Apple Silicon · circa 23 MB
  1. Scarica il DMG e aprilo.
  2. Doppio click su Cpython_interpreter_macos.app una volta.
  3. L’app si copia in Applicazioni, attiva cpy e stacca il disco.
  4. Se macOS blocca: Impostazioni → Privacy e sicurezza → Apri comunque.
Scarica per macOS

Dopo l’installazione

cpy version
cpy run tuoFile.cp

Poi il tutorial: primo programma, sintassi, sdgame e FinityEngine.

Antivirus

Alcuni antivirus segnalano l’exe PyInstaller come sospetto. È un falso positivo noto: il codice è pubblico, licenza MIT, build su GitHub Actions. Il programma non chiede i privilegi di amministratore e non parla con server esterni.

Dettagli, hash e come sbloccarlo: ANTIVIRUS.md.
