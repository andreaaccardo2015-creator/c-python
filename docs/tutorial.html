Tutorial C Python

C Python è un linguaggio per script e giochi: la sintassi sta a metà tra Python e C#, i file sono .cp o .cpy, e si lanciano con cpy run.

Non è l’interprete ufficiale di Python (CPython). È un linguaggio a sé, con installer proprio.

Cos’è

Con C Python scrivi programmi da terminale, minigiochi 2D e script per modelli 3D in FinityEngine. L’interprete capisce tipi dichiarati (int, float, string), blocchi con graffe o indentazione, e moduli come time, math, sdgame, finityengine.

File

Estensioni .cp e .cpy. I commenti sono // e stanno sotto gli import.

Esecuzione

Dopo l’install: cpy run tuoFile.cp in un terminale nuovo.

Installazione

I file pronti stanno nella pagina download. Repository: cpython-setup.

Windows

  1. Scarica Cpython_interpreter_64x_win.exe.
  2. Doppio click: installa demone, comando cpy e associazione dei file.
  3. Apri un nuovo terminale e prova cpy version.

macOS

  1. Scarica Cpython_interpreter_macos.dmg.
  2. Doppio click sul disco, poi doppio click su Cpython_interpreter_macos.app una volta.
  3. L’app si copia da sola in Applicazioni, attiva il demone e il comando cpy, e stacca il disco.
  4. Se macOS blocca: Impostazioni → Privacy e sicurezza → Apri comunque, poi ritenta.

Alcuni antivirus segnalano l’exe PyInstaller come sospetto. È un falso positivo noto: il codice è pubblico, licenza MIT. Dettagli in ANTIVIRUS.md.

Primo programma

Crea ciao.cp e lancialo con cpy run ciao.cp.

import time

// Il primo commento sta sempre sotto gli import

print.log("ciao da C Python")
string nome getinput("come ti chiami? ")
print.output("piacere,", nome)
time.breakcode(1)
  • print.log("...") scrive un messaggio: dentro va solo testo, non chiamate a funzione.
  • print.output(...) è quello che mostra risultati e valori: print.output("il totale fa:", a + b).
  • getinput("testo") chiede una stringa. Per un numero ci vuole sempre + f: float n getinput("numero" + f).
  • time.breakcode(1) aspetta un secondo (alias: time.sleep).

Le due print non sono la stessa cosa.

// no: la funzione non si chiama dentro print.log
print.log(add(2, 5))

// sì: il risultato prima in una variabile, poi print.output
int somma add(2, 5)
print.output("2 + 5 fa:", somma)

Sintassi

Tipi e variabili

Per dichiarare una variabile scrivi tipo, nome e valore: l’= non serve. Un valore float vuole sempre la f finale, anche quando è tondo.

int vite 3
float velocita 2.5f
float gravita 90f
string titolo "livello 1"
bool vivo true
list numeri [1, 2, 3]

// dopo, per cambiare un valore già dichiarato
vite += 1
velocita *= 2

Errori tipici.

float velocita = 2.5   // = di troppo, e manca la f
float velocita 2.5f    // così

Operatori: + - * / %, confronti == != < > <= >=, assegnamenti += -= *= /=, logica and or not. Costanti: true, false, null. I colori si scrivono #FFB74D.

Chiedere dati a chi gioca

Una stringa si chiede liscia. Un numero si chiede sempre con + f attaccato al testo della domanda, altrimenti quello che torna è testo e non ci fai i conti.

string nome getinput("come ti chiami?")
float numero1 getinput("qual è il primo numero?" + f)
float numero2 getinput("qual è il secondo numero?" + f)
print.output("la tua operazione fa:", numero1 + numero2)

If, while, for

Le graffe sono consigliate. L’if vuole la condizione tra parentesi. Un solo ramo: puoi omettere le graffe se il corpo è una riga.

if (vite <= 0) {
    print.log("game over")
} else {
    print.log("ancora in gioco")
}

int i 0
while (i < 3) {
    print.output("giro numero:", i)
    i += 1
}

for n in range(5) {
    print.output("n:", n)
}

Dentro i cicli: break e continue.

Nomi

Maiuscole e minuscole non contano: Player e player sono lo stesso nome. Vale anche per trasform / transform.

Giochi 2D · sdgame

Per un gioco 2D senza editor: apri la finestra tu, disegni ogni frame, chiudi alla fine.

import sdgame
import math

// Quadrato che si muove con WASD

sdgame.init(640, 480, "demo")
float x 100f
float y 100f

while (sdgame.is_running()) {
    sdgame.tick(60)
    if (sdgame.getkey("d")) { x = x + 200 * sdgame.dt() }
    if (sdgame.getkey("a")) { x = x - 200 * sdgame.dt() }
    x = math.clamp(x, 0, sdgame.width() - 40)
    sdgame.fill(#1A1F2B)
    sdgame.rect(x, y, 40, 40, #FFB74D)
    sdgame.text("A / D per muoverti", 16, 16, #FFFFFF, 22)
    sdgame.flip()
}
sdgame.quit()

Altri disegni: circle, line, image. Input: getkey (tenuto), getkeydown (appena premuto), mouse_x, mouse_y, mouse_button.

FinityEngine

Quando lo script vive nell’editor, la finestra la crea il motore. Non serve screen.create. Ogni script è figlio di un solo modello, tranne quelli agganciati all’intera scena.

  • Figlio del modello: non dichiari actor. move, animation e getcollision parlano di “questo” modello.
  • Figlio della scena: i modelli si nominano per intero (player.rb...).
  • Un solo on start, un solo on update, un solo on fixedupdate per script. Due uguali sono un errore.
import finityengine

// Script del modello player, stile editor

on start {
    animation.start("camminata")
}

on fixedupdate {
    // dt è sempre 1/60: il movimento non dipende dagli FPS
    float speed 240f
    if (finityengine.Input.GetKey("d")) {
        move(speed * dt, 0)
    }
}

on update {
    if (getcollision "muro") {
        animation.start("colpito")
    }
}

Fuori dall’editor, in uno script eseguibile da solo, dichiari actor player e alla fine chiami finityengine.Run().

Input: finityengine.Input.GetKey("space") (tenuto), GetKeyDown("space") (una volta). Tempo: finityengine.Time.deltaTime (frame) e fixedDeltaTime (passo fisso).

Animazioni e collisioni

Le clip le assegna l’editor al modello. Lo script le accende e le spegne per nome.

animation.start("gira")
if (animation.time "2") {
    animation.stop("gira")
}

animation.time "2" è vera quando l’animazione in corso ha raggiunto i 2 secondi. getcollision "muro" è vera se questo modello tocca l’attore chiamato muro. Le parentesi nell’if ci sono, ma la chiamata può stare senza: if (getcollision "muro") { }.

Rigidbody e parti del rig

Per usare la fisica da script la dichiari tu, anche se lo script è già figlio del modello:

rigidbody.call("RB")

on start {
    player.rb.trasform.part("braccio", y += 5)
}
  • y += 5 sposta di 5 sull’asse y.
  • y = 0 va a una posizione assoluta.
  • Ultimo numero opzionale: durata in secondi, con la f: part("testa", y += 90, x -= 10, 0.5f).

Se lanci lo script dall’editor con --ipc-stdio, C Python chiede a FinityEngine l’elenco dei componenti e delle parti. Se manca rigidbody o la parte "braccio", l’errore arriva subito, con file, riga e colonna.

Comandi

cpy version
cpy run gioco.cp
python -m cpython gioco.cp
python -m cpython --ipc-stdio gioco.cp
python -m cpython --no-jit gioco.cp

--ipc-stdio è il modo editor: handshake ready → bindings, poi convalida di actor, componenti e parti del rig. Senza quel flag lo script gira da solo, senza quella verifica.
