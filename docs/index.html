C Python

Un linguaggio per script, minigiochi 2D e modelli in FinityEngine. La sintassi sta a metà tra Python e C#, i file sono .cp o .cpy, e si lanciano con cpy run.

Non è l’interprete ufficiale di Python (CPython). È un linguaggio a sé, con installer proprio.

Scarica per Windows e macOS Apri il tutorial
Terminale

Programmi da riga di comando

Tipi dichiarati, funzioni, classi. Chiedi dati con getinput, scrivi con print.log e print.output.

2D

Giochi con sdgame

Finestra, tasti, rettangoli e testo. Un ciclo while e disegni ogni frame, senza editor.

3D

Script per FinityEngine

on start, on update, collisioni, animazioni e rigidbody. Uno script per modello.

Come si scrive

Tipo, nome e valore: l’uguale non serve. Un float vuole sempre la f.

import time

// Il primo commento sta sempre sotto gli import

print.log("ciao da C Python")
string nome getinput("come ti chiami? ")
print.output("piacere,", nome)
time.breakcode(1)

Due passi per partire

1. Installa

Windows: doppio click sull’exe. macOS: apri il DMG e lancia l’app una volta. Poi, in un terminale nuovo, cpy version.

Pagina download

2. Scrivi un file .cp

Crea ciao.cp e lancialo con cpy run ciao.cp. Gli esempi sono nel repository sorgente.
